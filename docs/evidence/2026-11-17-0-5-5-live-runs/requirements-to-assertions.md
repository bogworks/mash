# 0.5.5: requirements to assertions

This is the table the contract's section 8 ("Required evidence") asks for: one row for each REQ, INV, NFR and BND id of
`contracts/0.5.5-endpoint-model.md`, from the id to its evidence.

It maps to the records of the revisions listed in `README.md` of this directory: `record-at001-8fa36b8.md`,
`record-at002-8fa36b8.md` and `record-at003-8fa36b8.md` (AT-001 to AT-003 after #780), `record-at004.md` (the CLI team's
AT-004), `record-at005-bc96b27.md` (AT-005), and the completion checks (`completion-checks.md`, `old-form-search.md`,
`forbidden-word-test-output.txt`, `scrubcheck-output.txt`). The live-run records will be replaced by reruns on the final
release commit; after that the record file names and any reworded assertion names in this table are updated (ruling 16).

Assertion names are copied from the "Observed" lines of the records (the text after `pass: `); a name ending in `...` is
a prefix, and the record carries the rest of the line. File paths in the last column are relative to the repository root.
