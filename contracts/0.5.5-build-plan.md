# Build plan: mash 0.5.5, one endpoint model

Contract: `contracts/0.5.5-endpoint-model.md`, revision 4, ratified by the maintainer (decision 250, 2026-11-17).
Every item names the requirement ids it serves. Each item lands as its own pull request (or a short stack) from a
short-lived branch, held until the lead clears it. Sizes are from NFR-003.

## Order

1. C1 and T2 start now, in parallel. T2 needs nothing from the model.
2. C2, C1b and C5 start once C1 (#734) has landed. T1 and T3 start once C1 has landed.
3. C3 runs once C1, C2, T1 and T2 have landed.
4. C4 is built alongside C2 and C3, and runs once C3 passes. It needs three hosts that operations names (section 7 of
   the contract).
5. T4 is written alongside T1, and finished once C4's setup is known.
6. The final gate (`final-gate/STANDARD.md` 0.1.1) runs on the whole work, with operations' review lane, on the
   release commit, before any tag.
