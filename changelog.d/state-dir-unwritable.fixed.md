**`mash status` and `mash doctor` now notice a state folder mash cannot create.** When mash cannot create its state folder, `mash status` no longer says ready and `mash doctor` reports a failed delivery row that names the folder it cannot write. This is when mail waits for the spool, as the plugin sets it up (`MASH_SPOOL_FROM_START`, or `MASH_SPOOL_REQUIRED`); otherwise mail stays on the channel and is still delivered.
