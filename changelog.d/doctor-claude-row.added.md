**`mash doctor` checks your Claude Code version.** A new `claude` row, after `config`, runs `claude --version` and compares it with the versions mash is tested with: 2.1.312 is the minimum, and the tested series is 2.1. A newer Claude Code gets a warning, one that cannot be found is skipped, and one older than the minimum is a problem, so `mash doctor` now exits 1 on it. Scripts that run `mash doctor` will see exit 1 for an old Claude Code where it exited 0 before.
