**The local server setup now allows 1024 streams and 1024 consumers.** The script `mash-local-nats-setup.sh` used to give the account 64 streams and 128 consumers, so a server ran out of room after a few dozen endpoints. The disk limit stays at 2 GiB and is now the one you reach first, at about 122 endpoints. A server you already set up keeps its old limits (64 and 128); tested steps for raising them are tracked at https://github.com/bogworks/mash/issues/1301.
