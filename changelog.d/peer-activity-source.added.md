A session's activity (idle, working, done, blocked) is now read from herdr and from the plugin's hooks, and the `status` tool shows it as a new `activity:` line (`mash status` from a shell says a running session reports it). The new setting `MASH_ACTIVITY=auto|off` (`activity` in config.json) turns it off, and the plugin runs `mash hook` for the PermissionRequest, Stop, PreToolUse, PreCompact and PostCompact events too, and `mash hook` records the hook event it is given. Nothing is sent to peers yet; the sending side comes later.
