`mashctl policy serve` now applies a list set that adds addresses, as long as each address already has its inbox: for example the endpoints made with `mashctl add` before the account was adopted. The service still makes no inbox and issues no credential. An address with no inbox gets the list set refused before anything is pushed, and the status says the address has no inbox yet and that its endpoint must be provisioned first. `internal/admin` gains a read-only `CheckInbox`.
