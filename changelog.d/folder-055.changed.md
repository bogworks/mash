A configuration folder left by mash 0.5.5 (its `config.json` holds `url` or `tls_ca`) is now named for what it is: every command of `mash` and `mashctl` stops with `error: <folder> holds a mash 0.5.5 configuration` and a hint to run `mash-migrate-0.5.5.sh` from the release. Nothing is read from the old keys or changed, and `mash join` and `mashctl init` no longer call the folder a different server.
