The `send` receipt now shows the message's number in the text, in both `mash send` and the MCP tool: `Mail sent (number 42).`, `Urgent question mail sent (number 43).`, `Mail sent as fyi (number 44): a reply marked question that asks nothing.` The number is the message's place in the recipient's inbox, which the sender can find nowhere else. `--detail` adds only the `to:`, `kind:` and `urgent:` lines.
