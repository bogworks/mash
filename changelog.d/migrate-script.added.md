A release now also carries `mash-migrate-0.5.5.sh`, the one-time script for a machine that ran mash 0.5.5: `curl -fsSL https://github.com/bogworks/mash/releases/latest/download/mash-migrate-0.5.5.sh | bash` renames the two settings 0.5.6 renamed in `config.json` (`url` becomes `servers`, `tls_ca` becomes `ca`), keeps the old file beside it as `config.json.0.5.5`, and touches nothing on the server. It is listed in `SHA256SUMS` and attested like the other scripts ([ADR 0151](docs/decisions/0151-the-release-carries-a-one-time-0-5-5-migration-script.md)).
