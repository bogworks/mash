The global `--verbose` (and `-v`) is replaced by `--detail`, on every command of both `mash` and `mashctl`. It gives the fuller answer: in text, `label: value` lines after the usual line; with `--json`, a fuller object that contains the usual one. An MCP tool that has more to say takes a boolean `detail` the same way (today `status`: with `detail` it adds `reason_code` and `session`). A command with nothing more to say prints the same with or without it. `--verbose` and `-v` are now an unknown option, exit 2. In `mashctl`, `--detail` changes only `endpoint reissue`: it adds the line `servers acknowledged: N` and, with `--json`, the key `servers_acknowledged`. The extra lines `--verbose` gave `init` (the setup paths), `limits apply` (a line for each inbox), `endpoint create` and `endpoint delete` are gone, and so is the line `mashctl: target server ...` it printed to stderr before a verb connected to a server.
