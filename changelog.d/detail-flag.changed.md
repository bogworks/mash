The global `--verbose` (and `-v`) is replaced by `--detail`, on every command of both `mash` and `mashctl`. It gives the fuller answer: in text, `label: value` lines after the usual line; with `--json`, a fuller object that contains the usual one. An MCP tool that has more to say takes a boolean `detail` the same way (today `status`: with `detail` it adds `reason_code` and `session`). A command with nothing more to say prints the same with or without it. `--verbose` and `-v` are now an unknown option, exit 2.
