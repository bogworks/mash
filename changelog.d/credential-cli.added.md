mashctl credential: key, install, issue, show and revoke. `mash credential key` and `mash credential install` run on an endpoint's host with no server, environment or operator keys: the endpoint makes its own key (the seed goes to a file of mode 0600 and is never printed) and makes its creds file from the JWT that `mashctl credential issue --address owner.name --key PUBKEY` signed for its public key; `mashctl credential show` reports a key's issue record and connection and `mashctl credential revoke PUBKEY` revokes it. The same two endpoint verbs are in `mashctl`. `credential.RenderNextSteps` gives the text of a policy result's next steps; no command prints it yet.
