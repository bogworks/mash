mashctl credential: key, install, issue, show and revoke. `mash credential key` and `mash credential install` run on an endpoint's host with no server, environment or operator keys: the endpoint makes its own key (the seed goes to a file of mode 0600 and is never printed) and makes its creds file from the JWT that `mashctl credential issue --address owner.name --key PUBKEY` signed for its public key; `mashctl credential show` reports a key's issue record and connection and `mashctl credential revoke PUBKEY` revokes it. The same two endpoint verbs are in `mashctl`. `credential.RenderNextSteps` gives the text of a policy result's next steps; no command prints it yet. `mashctl credential issue --out FILE` refuses an existing FILE unless `--force` is given, and an overwrite writes a temporary file and renames it, so the old file is untouched if the write fails. `mashctl credential revoke PUBKEY --json` prints one object `{outcome, public_key, servers_acknowledged, refusal}`; exit 0 revoked or unchanged (already revoked), 1 refused (`not_found` when the key has no issue record and no account JWT revokes it), 5 partial (fewer servers than `--servers` acknowledged), 6 error.
