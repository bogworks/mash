`mashctl policy serve` now applies a list set that only adds an allow. Before, such a generation ended `partial` with "a connection open before the change is still open" for every sender: serve opened a check connection for every sender of the previous generation, and a push closes connections only when a group's template changes, so a pure widening could not pass. Serve now opens those connections only for the senders whose reach is removed or whose group's template changes with the push.
