**A 0.5.5 configuration folder is no longer migrated or named in an error.** The `mash-migrate-0.5.5.sh` script is no longer a release asset, and `mash` and `mashctl` no longer refuse a folder that still holds 0.5.5's keys; anyone with such a folder upgrades through 0.5.9 first, which still carries the script. This also removes the unchecked `curl | bash` command the old error printed ([#1446](https://github.com/bogworks/mash/issues/1446), [#1458](https://github.com/bogworks/mash/issues/1458)).
