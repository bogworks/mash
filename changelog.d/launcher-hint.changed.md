When mash is not installed, the plugin's session-start hook prints one line, "mash is not installed: the mash plugin found no mash program. Install it: curl ... install.sh | bash", so the agent can tell the person. The release base in it comes from the plugin's own release setting (`MASH_RELEASE_BASE`), so a fork or a mirror points at itself. The launcher's "no binary found" message is replaced by the same sentence.
