**`mash doctor` warns when the plugin runs a different mash than the one you are running (#1535).** A new `binary` row, after `claude`, takes the version from the plugin's pin file (`scripts/mash.pins`), finds the copy the plugin downloaded for it (`mash-<version>` under `$CLAUDE_PLUGIN_DATA/bin`) and warns when that version differs from the mash running doctor; it covers a doctor run by the plugin only, and from a shell the row is skipped.
