**`mashctl doctor` can accept keys that other tools issued on a shared account.** If your account has users that mash did not issue, list their exact user public keys (`U...`) in `config.json` as `external_keys`. A listed key that is connected no longer fails the `keys` check, and the line reads `every connected key was issued here or listed (1 external)`. Any key that is neither issued here nor listed still fails, and a malformed entry is a configuration error that names it. Without the setting nothing changes. Tracked at https://github.com/bogworks/mash/issues/1300.
