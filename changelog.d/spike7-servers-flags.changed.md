`mashctl add`, `reissue`, `retire`, `unzone` and `deprovision` take `--servers N` and `--sys-creds FILE`, and a command that stops on a server that is down says so: `retire` and `deprovision` print "nothing was revoked; the key is still valid" when the server set is short, and a stream that is offline is reported as a down server, not as a missing bucket (`audit`, `issued list` and `issued check` too). The refusal when fewer servers answer than the count says no longer mentions a zone policy, and "no servers available" adds a hint to check `MASH_URL` and that one listed server is up. The `MASH_URL` override warning is given only when an endpoint name or token is set.
