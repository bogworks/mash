`mash prompt <to> '{"ask":"state"}'` now delivers that text instead of failing with 400 "the envelope has no prompt". An argument that starts with `{` is sent as the prompt text, wrapped in an envelope for the receiver. To send a raw SAP envelope, use `mash prompt <to> --envelope '<json>'` ([ADR 0128](docs/decisions/0128-mash-prompt-always-sends-its-arguments-as-text-and-a-raw-envelope-needs-the-envelope-flag.md)).
