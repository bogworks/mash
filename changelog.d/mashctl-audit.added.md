`mashctl audit` lists mash's side of the population from the server and the creds directories, read only: every directory record and inbox stream (form, running or stopped, message count, first and last sequence, subjects), the orphans (inbox streams, lease keys and creds files with no directory record), and for every identity with an alias the drain state of its legacy inbox. `--json` is stable and versioned, `--strict` exits 1 on an orphan or an inbox not drained. See [docs/audit.md](docs/audit.md).
