The plugin launcher has a security stance setting: strict never runs an unverified binary (it refuses an unpinned plugin, re-verifies the cached binary on every run, and does not fall back to mash on PATH when the pinned binary cannot be fetched or verified); relaxed (the default) warns, re-fetches a cached binary that fails verification, and falls back ([ADR 0096](docs/decisions/0096-the-plugin-launcher-has-a-provisional-security-stance-setting.md)).
