An internal Go driver, `internal/policydirect`, applies a list-set document given as plain JSON to the account's servers with the same engine `mashctl policy serve` runs, for a caller that holds the account's keys: no submission bucket, no adoption marker, no signature and no running service. It refuses an adopted account, reports `applied`, `planned`, `unchanged`, `invalid`, `unsupported`, `stale`, `blocked`, `partial` or `error` with exit-code groups, and a dry run changes nothing and creates no bucket. There is no command for it yet.
