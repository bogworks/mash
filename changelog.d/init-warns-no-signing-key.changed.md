**`mashctl init` warns when the account lists signing keys and the setup file has no `signing_key` (#1255).** The operator may then require one, and `init` does not read the operator. The warning is one line on stderr, `warning: no signing_key in <setup file>, but the account lists signing keys`; the exit code stays 0 and the setup goes on. It is not printed when `signing_key` is set or a signing key is already stored.
