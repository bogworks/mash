# The policy tests that run on every mash release and on every change of the NATS server version mash ships with
# (REQ-020; docs/release.md, "Policy tests on every release"). The gate step `policy-tests` reads this file and
# `scripts/release-check --policy-tests` runs it alone.
#
# One row per test:  <AT id>  <package>  <test>  <status>  [note]
#   test     the name as `go test -json` reports it, subtests after a slash (spaces in a subtest name are underscores).
#            It becomes the -run pattern, so a test that is renamed or deleted never ran, and the gate refuses.
#   status   required: must be started and passed (a skip is not a pass).
#            pending:  no test on main yet; give "-" for package and test. It prints a notice and never fails, but
#            the gate refuses once a `func TestAT<NNN>...` for that AT exists in the tree: promote it to required.
#
# Every live test here runs an in-process nats-server (no network).
